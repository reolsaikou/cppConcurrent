There are three ways tested in this repository to implement shared counters.

First: use a global atomic counter shared with threads. 

Second: Use thread-local atomic variable to count, with a 10x performance against the first one.

Third: Use thread-local volatile variable to count, with a 15x performance against the second one, 150x performance against the first one.
